# 팀 Todo 백엔드 제품 요구사항

## 문서 목적

로컬 Todo와 과제 #5 공유 칸반 보드 API 및 `ttodo` CLI의 기능과 완료 기준을 정의합니다. API 동작은 `TSD.md`, 저장 구조는 `database.md`를 기준으로 합니다. CLI 범위는 `PRD_CLI.md`를 기준으로 합니다.

## 제품 개요

`ttodo`는 기본 Todo API와 과제 #5의 Supabase 칸반 보드 API를 사용하는 CLI입니다. 일반 Todo는 로컬 SQLite 또는 별도 PostgreSQL 저장소에 관리하고, `ttodo kanban`은 기존 공유 보드의 작업과 칼럼 관계를 사용합니다.

## 대상 사용자와 사용 환경

* 대상은 소규모 팀입니다.
* 기본 Todo 서버는 로컬 개발 환경에서 실행할 수 있습니다.
* 공유 API는 서버 토큰을 검사합니다. 계정별 로그인과 역할별 권한 관리는 제공하지 않습니다.
* 공유 보드 경로는 기존 Supabase 스키마를 직접 사용합니다.
* 실시간 동기화는 제공하지 않습니다. 클라이언트가 목록을 다시 조회해 최신 내용을 확인합니다.

## 목표

* 팀 할 일을 생성하고 조회하고 수정하고 삭제할 수 있습니다.
* 한 할 일에 여러 담당자를 지정할 수 있습니다.
* 상태, 마감일, 우선순위, 태그와 라벨로 할 일을 구분하고 조회할 수 있습니다.
* 완료 항목과 삭제 항목을 복구 가능한 방식으로 관리할 수 있습니다.
* API는 FastAPI 문서에서 탐색하고, CLI에서는 짧은 명령으로 호출할 수 있습니다.
* `ttodo kanban`으로 실제 팀 공유 보드에 작업을 만들고 조회할 수 있습니다.

## 기능 요구사항

### 할 일 관리

* 할 일을 생성하고 상세 내용과 목록을 조회하고 수정할 수 있습니다.
* 할 일은 제목을 필수로 가집니다. 설명, 마감일, 담당자, 태그, 라벨은 선택 입력입니다.
* 수정 요청은 전달한 필드만 변경합니다.
* 삭제 요청은 소프트 삭제로 처리합니다. 삭제된 데이터는 기본 조회에 나타나지 않습니다.
* 삭제된 할 일은 별도 조회와 복구가 가능합니다.

### 상태

* API 상태 값은 `assigned`, `in_progress`, `completed`입니다. 화면과 설명에서는 각각 `할당`, `진행 중`, `완료`라고 부릅니다.
* 사용자는 상태를 어떤 순서로든 변경할 수 있습니다.
* 상태를 전달하지 않고 생성하면 `할당`으로 시작합니다.
* 완료 항목은 목록 필터로 포함하거나 제외할 수 있습니다. 기본값은 포함입니다.

### 담당자

* 한 할 일에 담당자를 여러 명 지정할 수 있습니다.
* 로그인 기능이 없으므로 담당자는 서버가 확인하지 않는 이름 문자열입니다.
* 담당자 이름이 실제 팀원인지 확인하거나 이름별 권한을 부여하지 않습니다.
* 담당자가 없는 할 일도 허용합니다.

### 마감일과 우선순위

* 마감일은 선택 사항이며 시간대가 포함된 날짜와 시각으로 저장합니다.
* API 우선순위 값은 `low`, `medium`, `high`입니다. 화면과 설명에서는 각각 `낮음`, `보통`, `높음`이라고 부릅니다.
* 우선순위를 생략하면 API 값 `medium`으로 설정합니다.

### 태그와 라벨

* 태그와 라벨은 각각 사용자가 자유롭게 입력하는 문자열 목록입니다.
* 목록 조회에서 태그와 라벨을 조건으로 사용할 수 있습니다.
* 같은 할 일 안에서는 앞뒤 공백을 제거한 뒤 중복 값을 하나로 취급합니다.

### 공유 칸반 보드

* `POST /api/v1/kanban/tasks`는 기존 프로젝트에 작업을 만들고 보드 칼럼에 배치합니다.
* `GET /api/v1/kanban/tasks`와 `GET /api/v1/kanban/tasks/{task_id}`는 보드 작업을 조회합니다.
* 상태는 `board_items`와 `board_columns`가 연결하는 `workflow_statuses.category`에서 계산합니다.
* 담당자는 해당 workspace 멤버 프로필인지 확인하고, 라벨은 기존 프로젝트 라벨 관계로 저장합니다.

## 범위에서 제외하는 기능

* 회원 가입, 로그인, 팀원 인증과 권한 관리
* 여러 팀 또는 프로젝트 공간 관리
* 실시간 알림, 이메일 알림, 푸시 알림
* 변경 이력과 감사 로그
* 반복 일정과 하위 할 일

## 성공 기준

* FastAPI 문서와 `ttodo` CLI에서 할 일 생성, 조회, 수정, 소프트 삭제, 복구를 실행할 수 있습니다.
* 할 일 하나에 담당자 여러 명을 저장하고 다시 조회할 수 있습니다.
* 세 상태를 자유롭게 변경하고 상태 조건으로 목록을 조회할 수 있습니다.
* 완료 항목 포함 여부를 필터링할 수 있습니다.
* 태그, 라벨, 담당자, 우선순위, 마감일 조건으로 목록을 좁힐 수 있습니다.
* 공유 칸반 보드에 작업을 저장하고 상세 API와 CLI 목록에서 다시 확인할 수 있습니다.
* 소프트 삭제된 항목은 기본 목록에서 보이지 않고, 삭제 항목 조회와 복구가 가능합니다.
* 서버를 재시작해도 SQLite 파일에 저장한 데이터가 유지됩니다.

## 미결정 또는 전제

* 기본 Todo 저장소의 팀원 수와 데이터 보존 기간은 정해지지 않았습니다.
* 담당자 문자열은 자유 입력이므로 표기 흔들림이나 동명이인을 구별하지 못할 수 있습니다.
* 데이터베이스 파일 백업과 초기화 절차는 구현 단계에서 실행 문서와 함께 정합니다.
