# ttodo CLI 제품 요구사항

## 목적과 기준

이 문서는 비개발자도 터미널에서 Team Todo API를 사용할 수 있도록 하는 `ttodo` CLI의 사용자와 기능 범위를 정의합니다. API의 경로와 요청 형식은 실행 중인 백엔드의 `/openapi.json`을 기준으로 하며, 세부 구현은 `TSD_CLI.md`를 따릅니다.

## 제품 개요

`ttodo`는 Python과 Typer로 만든 명령줄 도구입니다. 기본 주소 `http://127.0.0.1:8000`의 Todo API에 연결해 할 일을 생성, 조회, 수정, 소프트 삭제하고 복구합니다. 명령은 인수와 옵션만으로 실행합니다. 기본 출력은 읽기 쉬운 텍스트이며 `--json`을 지정하면 성공 결과를 JSON으로 출력합니다.

## 사용자와 실행 환경

- 터미널 명령에 익숙하지 않아도 도움말을 따라 Todo API를 사용하려는 사람
- Python 3.13
- macOS, Linux, Windows
- `uvx`를 통한 로컬 패키지 실행
- 공개 패키지 저장소 배포는 초기 범위에 포함하지 않습니다.

## 기능 요구사항

### 명령

- `ttodo create`: 할 일을 생성합니다.
- `ttodo list`: 활성 할 일과 필터 결과를 조회합니다.
- `ttodo get <task_id>`: 활성 할 일의 상세 정보를 조회합니다.
- `ttodo update <task_id>`: 지정한 필드만 수정합니다.
- `ttodo delete <task_id>`: 할 일을 소프트 삭제합니다.
- `ttodo deleted`: 삭제된 할 일 목록을 조회합니다.
- `ttodo restore <task_id>`: 삭제된 할 일을 복구합니다.

생성과 수정은 제목, 설명, 상태, 우선순위, 마감일, 담당자, 태그, 라벨을 지원합니다. 목록은 API가 제공하는 상태, 담당자, 우선순위, 마감일, 태그, 라벨, 완료 여부, 페이지 필터를 지원합니다. 허용 값과 기본값은 `TSD_CLI.md` 및 OpenAPI 계약을 따릅니다.

### API 범위 추적

- 모든 업무 operation과 입력 parameter를 CLI 명령 및 테스트에 연결합니다.
- 새 operation이나 parameter에 대응하는 CLI 입력과 테스트가 없으면 완전성 검사가 실패해야 합니다.
- `/docs`, `/redoc`, `/openapi.json` 같은 문서 경로는 업무 operation에서 제외합니다.

### 도움말

- 루트와 하위 명령 도움말은 비개발자가 이해할 수 있는 짧은 영어로 작성합니다.
- 명령 설명에는 목적, 필요한 입력, 기본 동작, 되돌릴 수 있는지 여부를 안내합니다.
- 옵션 설명에는 값의 의미, 허용 형식, 생략 시 동작, 반복 지정 여부를 안내합니다.
- 모든 명령 도움말에 복사해 실행할 수 있는 기본 예시와 JSON 예시를 제공합니다.
- 옵션과 기본값은 이 문서, `TSD_CLI.md`, `TEST_CASE_CLI.md`에서 일치해야 합니다.

### 출력과 오류

- 기본 성공 출력은 필드와 값을 읽기 쉬운 텍스트로 표시합니다.
- `--json` 성공 출력은 파싱 가능한 JSON이어야 하며 API 응답 구조를 보존합니다.
- 오류 메시지는 표준 오류에 출력하고 0이 아닌 종료 코드로 끝냅니다.
- 잘못된 입력, 연결 실패, API 오류에 다음 조치를 알 수 있는 간결한 설명을 제공합니다. 기본 출력에 traceback을 표시하지 않습니다.

### API 주소

- 기본 주소는 `http://127.0.0.1:8000`입니다.
- `--base-url` 또는 `TTODO_BASE_URL`로 주소를 바꿀 수 있습니다.
- 적용 순서는 `--base-url`, `TTODO_BASE_URL`, 기본 주소입니다.
- 공유 서버가 `TTODO_API_TOKEN`을 요구하면 같은 이름의 환경 변수로 전달할 수 있습니다. 토큰은 CLI 인수로 받지 않습니다.

## 범위에서 제외하는 기능

- API 서버나 OpenAPI 명세를 생성, 수정하는 기능
- 대화형 입력, TUI, 셸 완성 기능
- 계정별 로그인과 역할별 권한 관리
- 임의의 OpenAPI 서버를 호출하는 범용 도구
- 초기 버전의 PyPI 등 공개 저장소 배포

## 완료 기준

- OpenAPI에 정의된 업무 operation과 입력 parameter가 CLI 및 테스트에 연결되어 있습니다.
- 모든 명령을 대화형 입력 없이 실행할 수 있고, 도움말에는 실행 가능한 예시가 있습니다.
- 기본 텍스트와 JSON 출력, 주소 설정, 오류 스트림과 종료 코드가 요구사항을 따릅니다.
- `uvx --from ./cli ttodo --help`가 동작하고 `bash scripts/verify.sh`가 통과합니다.
- macOS, Linux, Windows의 Python 3.13 환경에서 설치와 실행을 확인합니다.

## 계약 관리

백엔드 `/openapi.json`이 API 계약의 원본입니다. `cli/openapi.json`은 생성 클라이언트와 테스트에서 사용하는 저장된 명세입니다. 현재 저장된 명세는 OpenAPI 3.1.0이며 업무 operation 7개를 포함합니다. 갱신 절차와 알려진 API 문서 차이는 `TSD_CLI.md`에서 관리합니다.
